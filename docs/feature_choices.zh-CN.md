# 哪类图片特征真的有助于预测不同观测者的偏好？

最终目标不是"描述一张猫图"，而是**预测某位观测者会选 A 还是 B**。因此判断特征族的标准是偏好预测指标，
而不是描述看起来多丰富。

下面所有数字都在同一份数据、同一类估计器（L2 逻辑回归，`fit_intercept=False` + 显式 side 列，`C = 1`）、
同一套按图对分组的折上测出（`scripts/07_feature_families.py`）。

## 1. 用哪些指标，为什么是这些

| 指标 | 回答的问题 | 为什么在这里重要 |
|---|---|---|
| log loss / Brier | 概率质量 | 提交的是概率 `prob_a`，不只是一个方向 |
| accuracy | argmax 命中率 | 直观，但常数预测器已有 0.52 |
| **分观测者增益** | 该特征族是否对 70 种观测者画像**都**优于"该画像自己的常数预测器" | 只对部分人有效的特征不是好特征 |
| **重复图对的一致性**（0.557）与**一致图对上的准确率** | 两个不同的人看同一图对时有多少稳定成分 | 这是任何图对级模型的学习上限 |
| **校准**（ECE、重校准斜率） | 概率能不能当概率用 | 下游决策与概率融合都依赖它 |
| **冷启动 1 / 2** | 两张图都没见过 / 两只猫都没见过 | 测试集 25% 的行是双新图，约 40% 涉及新猫 |

分观测者指标的注意点：70 种画像各自看到的图对不同，所以画像间差异有一部分是"看了哪些图"而非"人有多难预测"。
增益列（模型 log loss 减去该画像常数预测器的 log loss）消掉了"该画像本身接近 50/50"的部分，是更公平的那个。

## 2. 参与比较的特征族

| 特征族 | 是什么 | 能表达 | 不能表达 |
|---|---|---|---|
| 仅观测者 | 6 个人口学字段的 26 维 one-hot | "某类人偏好 X"这类总体效应 | 任何关于图片的信息 |
| 标签（毛色） | YOLO 掩码上的毛色占比（像素颜色） | 毛色构成 | 姿态、品种、构图，以及一切未标注属性 |
| 标签（全部） | 毛色 + 花纹/品种/姿态/视角/眼睛/景别 | 一套粗粒度的人类词汇 | 细节纹理、背景、光线、审美 |
| 手工统计（20） | 亮度、对比度、饱和度、彩色度、清晰度、熵、边缘、色相、曝光、尺寸 | 摄影质量类属性 | 画面里**是什么** |
| 稠密嵌入（576） | 冻结 ImageNet MobileNetV3-Small 池化向量 | 从 130 万张图学到的任意外观方向 | 无命名维度；无逐猫记忆 |
| 猫记忆 | 每只猫一个强度（逐猫效应） | "cat_000123 通常更受欢迎" | 没参与拟合的猫 |
| 混合 | 猫记忆 + 嵌入（+ 手工 / 标签）一次联合拟合 | 上述两者 | 联合设计下仍救不了新猫 |

## 4. 直白解读：各自的优劣

**观测者人口学 —— 基本不算特征。** 0.6900，比常数基线还差（常数即 0.6925 附近；对 93% 的画像来说，
"该画像自己的常数"都优于这个模型）。6 个背景字段与 `choice` 的 Cramér's V 全部低于 0.05。
标注者背景几乎不能告诉你他会选哪张图，不值得在这里投入特征预算。

**低层统计（20 维）—— 便宜、可解释、弱。** 0.6865（比常数好 0.006）。对多数画像都有一点帮助（56%），
画像间波动小，但完全无法区分画面内容。适合作为报告里的可解释协变量（"更亮的图被选中的比例略高"），
不适合作为主力预测器。

**粗粒度语义标签 —— 预测弱，校准极好，迁移到新猫最强。** 毛色 0.6828，全标签 0.6800。
两个亮点：概率几乎完美校准（ECE 0.007，斜率 0.99）；在**两猫都未见**时它是全部特征族里最好的
（0.6805，优于 576 维嵌入的 0.6869）。这正是"粗属性可以替代缺失的逐项分数"这句话的定量版本。
代价是分辨率：在两位观测者意见一致的图对上，标签只能命中 60–62%，而嵌入 67%、混合 70%。

**冻结稠密嵌入 —— 最好的纯视觉描述。** 0.6674，比常数好 0.025，73% 的画像被帮助，
强模型中校准最好（ECE 0.006）。能迁移到新图（0.6797），对全新猫也仍优于基线（0.6869）。
缺点：完全不可解释（576 个无名维度）；而且它**主要在编码"是哪只猫"**——猫没见过时优势从 0.025 掉到 0.006。

**逐猫记忆 —— 见过猫时最强，也最脆。** 总体 0.6600，在"两人答案一致"的图对上准确率 0.690（仅次于混合），
是最"懂共识"的单一模型。但它本质是查表：两猫都没见过时直接退化到基线（0.6913），
并且画像间最不均匀（增益标准差 0.058）、校准最差（斜率 0.88）。

**混合 —— 平均最好，冷启动最差。** `猫 + 嵌入 + 手工` 总体最优（0.6565，73% 画像被帮助，
一致图对 0.699），但在全新猫上明显**不如任一部分单独使用**（0.6945 vs 嵌入 0.6869、猫记忆 0.6913）。
原因是联合拟合时猫哑变量先吃掉猫级方差，嵌入权重只能解释残差，迁移能力下降。
这是"一次联合拟合"的设计缺陷，不是嵌入本身的问题：应当按"猫是否见过"分流。

## 5. 什么目标用什么特征

| 目标 | 最佳选择 | 依据 |
|---|---|---|
| 在这份测试集上要最小 log loss | 混合（猫 + 嵌入 + 手工） | 0.6565；一致图对 0.699 |
| 预测必须扛住全新猫 | 毛色标签，或纯嵌入 | 双新猫 0.6805 / 0.6869，混合是 0.6945 |
| 报告里需要可解释的故事 | 毛色标签 + 手工统计 | 几乎完美校准（ECE 0.007）且有具名维度 |
| 最小最快的流水线 | 仅手工统计（不用 CNN） | 每张图几毫秒，0.6865 |
| 只靠观测者背景 | 不用 | 比常数预测器还差 |

## 6. 局限

* **没有标注者 ID。** "不同观测者"只能用 70 种完整人口学画像近似（另有 508 行六个字段全空）。
  画像看到的图对集合不同，所以画像间差异混入了图对构成；增益列缓解但不消除。
* **一致性封顶。** 两人在重复图对上的答案一致率 55.7%（Cohen's kappa ≈ 0.11）。
  分歧图对上所有模型都在 0.50 —— 那里没有稳定信号可学。可以把"一致图对上约 0.70"视为接近上限。
* **两种冷启动，通常只报一种。** 省掉"两猫都未见"那一列，会让逐项记忆模型显得比实际更好。
* **标签表是读取而非重生成**（`artifacts/labels/` 里的 YOLO11n-seg + CLIP 表），标签行继承了那条流水线的选择；
  嵌入与手工特征行由本项目生成。
* 单一数据集、单一随机种子，所有族统一 `C = 1`。相邻特征族之间的 0.001–0.003 差异在噪声内，
  族与族之间 0.005–0.03 的差异不是。
* 测试集标签未公开，以上都不是排行榜分数；上述三种协议才是诚实的代理。

## 6b. 换更强的特征能补上短板吗？（不能——分流才行）

混合模型平均最好、冷启动最差。测了两条补救路线（`scripts/08_cold_start_fix.py`），
验收标准是*平均 ≤ 0.6565* **且** *两猫都未见 ≤ 0.6892*（各特征族在该切片的中位数）。

**路线一：更强的特征。** 把 ResNet18 与 MobileNetV3-Small 的嵌入拼接（1088 维），
见过的猫上全面提升，冷启动反而更差：

| 外观特征 | 平均 | 两图未见 | 两猫未见 |
|---|---:|---:|---:|
| 嵌入 + 手工 + 毛色（596 + 5） | 0.6659 | 0.6798 | 0.6874 |
| 再加 ResNet18 拼接（1113） | **0.6607** | 0.6801 | **0.6938** |
| 单主干特征 + 联合混合模型 | **0.6565** | 0.6847 | 0.6945 |
| 多主干特征 + 联合混合模型 | 0.6567 | 0.6897 | 0.6968 |

容量更大换来分布内精度，却**牺牲了迁移**：多出来的维度更擅长编码"是哪只猫"，
而这恰恰是新猫用不上的。把毛色 shares 加进外观块，冷启动只变化约 0.001（噪声级）。

**路线二：不要用一个模型干两件事。** 分别拟合联合模型与迁移模型（只用毛色 shares），
预测时按"这只猫、这张图是否出现在训练集"来选择分支——这个信息不含标签、提交时即可算出。

| 模型 / 分流 | 平均 | 两图未见 | 两猫未见 | 同时满足 |
|---|---:|---:|---:|:--:|
| 联合（一个模型打天下） | 0.6565 | 0.6847 | 0.6945 | 否 |
| 分流：**猫+图**都见过用联合，否则用标签 | **0.6565** | **0.6823** | **0.6805** | **是** |
| 分流：**猫**见过就用联合，否则用标签 | 0.6565 | 0.6844 | 0.6805 | 是 |
| 各特征族中位数（要越过的门槛） | — | 0.6837 | 0.6892 | — |

分流模型保住了最好的平均分，同时越过两个冷启动中位数：新图好 0.0014，新猫好 0.0087。
测试集上 50% 的行走联合分支。分流信号是"该条目是否出现在训练数据中"，提交时就已知，不涉及测试标签。

**对特征设计的启示：** 平均最优模型的短板不是"特征不够好"，更多特征只会让平均更好、短板更差。
真正的病因是联合拟合让逐项记忆挤占了共享表示。正确解法是保留一个专门的迁移模型并按需分流。
