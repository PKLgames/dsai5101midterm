# Ready-to-use train / test tables

Generated by `scripts/06_export_tables.py` from the feature cache and the course CSVs.
One row per annotator response, so a model can be trained without touching any code in this repo.

| File | Rows × cols | Size | Contents |
|---|---:|---:|---|
| `train_pairs.csv.gz` | 24,896 × 636 | 58 MB | features + observer profile + observed `choice` |
| `test_pairs.csv.gz` | 6,224 × 634 | 15 MB | same columns, labels removed |
| `image_features.csv.gz` | 1,558 × 598 | 3.4 MB | per-photo table (deep 576-d + hand 20-d) |

Regenerate with:

```bash
.venv/bin/python scripts/06_export_tables.py            # default MobileNetV3-Small cache
.venv/bin/python scripts/06_export_tables.py --tag resnet18_224 --out-dir tables/resnet18
```

## Columns of `train_pairs.csv.gz` / `test_pairs.csv.gz`

| Block | Columns | Meaning |
|---|---|---|
| identity | `train_row_id` / `test_row_id`, `a_cat`, `b_cat`, `a_image`, `b_image`, `comparison_type` | the response and the two photos (`a_image` is the path relative to `artifacts/images/`) |
| observer profile | `gender`, `pet_history`, `pet_care`, `pet_contact`, `future_pet`, `mbti_ie` | exactly as recorded; blanks are written as `missing` |
| profile one-hot | `demo_<column>_<level>` (26 columns) | the encoding the models actually use, `missing` included |
| image features | `d_0000 … d_0575` | embedding difference `f(A) − f(B)`, L2-normalised per photo |
| low-level features | `h_<name>` (20 columns) | hand-statistic differences, same A−B convention |
| label (train only) | `choice`, `y` | `"A"`/`"B"` and `1`/`0` for "chose A" |

`test_pairs.csv.gz` has no `choice` / `y` column.

## Using it

```python
import pandas as pd
from sklearn.linear_model import LogisticRegression

train = pd.read_csv("tables/train_pairs.csv.gz")
feat = [c for c in train.columns if c.startswith(("d_", "demo_"))]
clf = LogisticRegression(C=0.003, max_iter=400).fit(train[feat], train["y"])
```

Measured: this two-line model reaches **0.665 log loss** (pair-grouped 5-fold) on the
train table, i.e. the exported columns are exactly the ones the pipeline uses.

## Notes and caveats

* The features are **differences** `f(A) − f(B)`, not per-side vectors. To recover per-side
  features, join `a_image` / `b_image` against `image_features.csv.gz` on `image_path`.
* Everything is float32 printed with 6 significant digits.
* `test_pairs.csv.gz` has no labels — the course withholds them, so nothing here can score it.
* The labels and the observer columns come from `course/train.csv` and `course/test.csv`;
  the features come from `artifacts/features/<tag>.npz` (see `scripts/03_extract_features.py`).
* These files are **not** committed to git (see `.gitignore`): 58 MB would bloat the repository.
  Upload them as a release asset, with Git LFS, or via the course submission package.
